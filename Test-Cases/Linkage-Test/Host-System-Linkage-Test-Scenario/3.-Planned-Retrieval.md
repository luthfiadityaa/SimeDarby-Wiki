# Technical Implementation Notes

*   **Process Trigger:** All tests follow the `HostCommExecutor -> recvRetrievalPlanData()` execution path.    
*   **Error Handling:** In negative scenarios, data is typically routed to `C:\daifuku\data\oldData\ShippingProcess_<MaterialNum>_YYYYMMMDD_hhmmss-xxx.err`.    
*   **Logging:** Error details are captured in `DNExchangeHistory` and `DNLoaderErrorInfo`.
