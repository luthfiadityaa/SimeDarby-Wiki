# Verification SQL
Execute the query below to verify the interface record generated for SAP reporting:

```sql
SELECT 
  DNHOSTSEND.*, 
  WI.BCR_DATA AS PALLET_ID, 
  IT.UOM AS UOM 
FROM 
  DNHOSTSEND 
  JOIN DNWORKINFO WI ON WI.STOCK_ID = DNHOSTSEND.STOCK_ID 
  JOIN DMITEM IT ON IT.ITEM_CODE = DNHOSTSEND.ITEM_CODE 
WHERE 
  DNHOSTSEND.REPORT_FLAG = '0' 
  AND DNHOSTSEND.JOB_TYPE = '24' 
  AND EXISTS (
    SELECT 
      1 
    FROM 
      DNWORKINFO WI 
    WHERE 
      WI.PLAN_UKEY = DNHOSTSEND.PLAN_UKEY
  ) 
ORDER BY 
  DNHOSTSEND.PLAN_DAY ASC, 
  DNHOSTSEND.REGIST_DATE ASC
```
