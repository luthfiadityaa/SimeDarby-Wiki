#Palletize Start - Set(F2)
Palletize Start is used to set the information of stock which will be palletized by robot automatically. After **Set(F2)**, all items in input text will be added into a Pallet Number. The result will be posted back to SAP as [Production Storage Result](https://dev.azure.com/Daifuku-SW/ID_SimeDarbyPlantation/_wiki/wikis/ID_SimeDarbyPlantation.wiki/840/Production-Storage-Result)

##<span style="color:skyblue; font-weight:bold">Validations</span>
This section explains the validations for the whole proccess Palletize Start

- Planned Carton Qty, Qty crtn/PL, Tempering Period and Expiry Days must be greater than 0.
- Qty crtn/PL cannot greater than Planned Carton Qty.

[WIP] 

- Selected Station Number is NOT under suspend. <span style="color:green; font-weight:bold">(DMStation.SUSPEND.OFF)</span>
- Selected Station Number is available. <span style="color:green; font-weight:bold">(DMStation.STATUS.NORMAL and DMStation.STATUS_FLAG.ACTIVE)</span>
- No Active (StatusFlag 0,1,2) DNReceivingplan in this station
- <span style="color:green; font-weight:bold">Quantity (Carton per Pallet)</span> must be greater than <span style="color:green; font-weight:bold">0</span>.
- <span style="color:green; font-weight:bold">Planned Carton</span> must be greater than or equal to <span style="color:green; font-weight:bold">Quantity (Carton per Pallet)</span>.
- Material Code exists in <span style="color:green; font-weight:bold">DMITEM</span>
- Input text with red asterisk <span style="color:red">(*)</span> is not empty
- If the actual Carton Qty exceeds the planned Qty, continue the storage operation.
  Ex.)
  Planned Carton Qty: 1000
  Actual: 1010
  The purpose to show the Planned Carton Qty is to have the history purpose.
  With this history, user can detect the result is abit exceeded from plan.
  So the Planned Carton Qty doesn't directly affect to the number of Pallet or Carton in Storage Operation.


##<span style="color:skyblue; font-weight:bold">Table Operation DML</span>

###<span style="color:skyblue; font-weight:bold">DNReceivingPlan</span>
*   **PLAN_UKEY** : Sequence Object    
*   **STATUS_FLAG** : 0: Not Started    
*   **CANCEL_FLAG** : 0: Normal Data     
*   **PLAN_DAY** : Value from screen (**Storage Date/Time**)    
*   **PLAN_AREA_NO** : Value from screen (**Storage Location**) : **FGW1 (Ambient/9002)** or **FGW2 (Tempering/9001)**    
*   **ITEM_CODE** : Value from screen (**Material Code**) -> **<span style="color:green; font-weight:bold">DMITEM.ITEM_CODE </span>**   
*   **PLAN_QTY** : Value from screen (**PLANNED CARTON QTY**)    
*   **REPORT_FLAG** : 0: Not Reported     
*   **BATCH_STATION_NO** : Value from screen (**Station No**)     
*   **PLAN_LOT_NO** : Value from screen (**Batch_No**)    
*   **BATCH_QTY_CTRN_PLT** : Value from screen (**QtyCrtnPL**)    
*   **BATCH_TEMPERING_PERIOD** : Value from screen (**Tempering Period**)    
*   **BATCH_EXPIRY_DAYS** : Value from screen (**Expiry Days**)        
*   **BATCH_START_DATETIME** : **PLAN_DAY + System Timestamp (Time Value)**    
*   **SAP_TO_LOCATION** : Value from screen **(Storage location)** [DMArea] FGW1, FGW2
*   **MSG_TYPE** : 1: Production Storage
*   **REGIST_DATE** : SYSTIMESTAMP    
*   **REGIST_PNAME** : ClassName    
*   **LAST_UPDATE_DATE** : SYSTIMESTAMP    
*   **LAST_UPDATE_PNAME** : ClassName
