# **3. Batch End**

**Flow Process (User Process)**

::: mermaid

graph TD
    A[Start: User Input Last Pallet Qty] --> B{Qty == 0?}
    
    B -- Yes --> C[Update DNStoragePlan Status = 4]
    C --> E([End: Batch Completed])
    
    B -- No --> F[Update DNStoragePlan Status = 2]
    F --> G[User Triggers Robot Force Completion]
    G --> H[Pallet Moves to Station 111X]
    H --> I([Wait for ID26 Force Completion])
:::


**Sequence Diagram**

::: mermaid

sequenceDiagram
    participant U as User
    participant WN as WMS Screen
    participant R as Robot
    participant DB as WMS Database
    participant AGC as AGC System

    U->>WN: Input Qty > 0 & Submit
    WN->>DB: Update DNStoragePlan Status=2 (Waiting)
    U->>R: Trigger Force Completion
    R->>AGC: Release Pallet to 111X
    AGC->>DB: Send ID26 (Force Completion)
    
    Note over DB: Validate Status=2
    DB->>DB: Update Stock, Pallet, & Plan (Status=4)
    DB->>DB: Find Location & Create CarryInfo
    
    DB->>AGC: Send ID05 (Move to Storage)
	
:::

**Flow Process (Background)**

::: mermaid
graph TD
    Start[ID26 Force Completion @ 111X] --> CheckData{DNStoragePlan Found?}
    
    CheckData -- No --> Reject[Transfer to 1303: Reject]
    
    CheckData -- Yes --> Status{Status Flag?}
    
    Status -- "1: Working" --> Warning[Tower Light ON: Warning]
    Warning --> Reset[Error Reset/Wait for Batch End]
    
    Status -- "4: Completed" --> Reject
    
    Status -- "2: Waiting" --> Finalize[WMS Updates Inventory]
    Finalize --> UpdateTables[Update DNStock, DNPallet, DNStoragePlan]
    UpdateTables --> FindLoc[Search Empty Location]
    FindLoc --> Storage[Create Work/Carry Info & Send ID05]
:::

When `Status_Flag = 2` is processed, the following data updates occur simultaneously.

| Table | Column | New Value / Logic |
| --- | --- | --- |
| **DNStock** | `ITEM_CODE` | `DNStoragePlan.ITEM_CODE` |
| **DNStock** | `PLAN_QTY` | `DNStoragePlan.BATCH_QTY_CTRN_PL` |
| **DNPallet** | `EMPTY_FLAG` | `0` (Loaded) |
| **DNStoragePlan** | `PROCESS_QTY` | `PROCESS_QTY + BATCH_QTY_CTRN_PL` |
| **DNStoragePlan** | `RESULT_QTY` | Final `PROCESS_QTY` |
| **DNStoragePlan** | `WORK_DAY` | Today's Date |
| **DNStoragePlan** | `STATUS_FLAG` | **4** (Completed) |


## *1. Abnormal Process*

**User Force complete at robot, but it is empty pallet**

graph TD

    C -- "1: Working" --> D[Trigger Warning / Tower Light]
    D --> E[Wait for User: Batch End Screen]
    
    E --> F{User Inputs Qty?}
    F -- "Qty = 0" --> G[Update DNStoragePlan Status = 4]
    G --> H[Update DNHostSend]
    H --> I[Send ID05: Move Pallet to 1303 REJECT]
    
    C -- "2: Waiting" --> J[Process as Last Pallet Storage]
:::
