# **2. Batch Start**

## **1.  Batch Start Setting**

::: mermaid
graph LR
    User((User)) -- "Input Data" --> Warenavi[Warenavi Interface]
    SystemClock[[System Clock]] -- "Timestamp / Day" --> Logic[WMS Processing Logic]
    Warenavi -- "Raw Input" --> Logic
    Logic -- "Mapped Record" --> DNStoragePlan[(DNStoragePlan Table)]
	
:::

####<span style="color:skyblue; font-weight:bold">DNStoragePlan</span>

| Input Field | Database Column | Logic / Note |
| :---- | :---- | :---- |
| Material Code | ITEM\_CODE | User Input |
| Batch No | PLAN\_LOT\_NO | User Input |
| Planned Carton Qty | PLAN\_QTY | User Input |
| Expiry Days | BATCH\_EXPIRY\_DAYS | User Input |
| Storage Location | PLAN\_AREA | User Input (FGW2:9001 or FGW1:9002\) |
| Qty Carton/Pallet | BATCH\_QTY\_CTRN\_PL | User Input |
| Planned Carton Qty | PLAN\_QTY | User Input |
| Station No | BATCH\_STATION\_NO | User Input (1101 to 1105\) |
| Tempering Period | BATCH\_TEMPERING\_PERIOD | User Input |
| Storage Date/Time | BATCH\_STORAGE_\_DATETIME | User Input |
| System Timestamp | BATCH\_START\_TIME | Current Date \+ Time |
| System Day | PLAN\_DAY | Current Date |
| Calculated Key | STORING\_PAIR\_KEY | ITEM\_CODE \+ PLAN\_LOT\_NO |
| Calculated Key | LOAD\_UNIT\_KEY | Web-St-"+YYYYMMDDhhmmss |
| FIXED | STATUS\_FLAG | 0: Not Started |
| FIXED | REGIST\_KIND | 1: Entry by terminal |
| FIXED | CANCEL\_FLAG | 0: Normal Data |
| SEQUENCE | PLAN\_UKEY | STORAGE_PLANUKEY_SEQ |
