## **2.  BACKGROUND PROCESS (PrePalletizeStationOperator)**


### **2.1  Supply Empty pallet to Robot Station**

**Flow Process**

::: mermaid
graph TD
    A[Start: Operator Check] --> B{Record in<br/>DNStoragePlan?}
    B -- No --> C[Stop: No Active Batch]
    B -- Yes --> D{Any Pallet at<br/>Station 111X?}
    
    D -- Yes --> E[Ignore: Destination Occupied]
    D -- No --> F{Empty Pallet at<br/>Station 110X?}
    
    F -- No --> G[Stop: No Source Pallet]
    F -- Yes --> H[Update DNPallet:<br/>SET CURRENT_STATION_NO = 111X]
    
    H --> I[Send ID05 Transfer Command]
    I --> J[Move ST110X to ST111X]
    J --> K([End: Transfer Initiated])
:::

**Sequence Diagram**

::: mermaid
sequenceDiagram
    participant Op as Operator / System
    participant DB as WMS Database
    participant TS as Transfer System (ID05)

    Note over Op, DB: Check Target Station
    Op->>DB: Query DNPallet WHERE CURRENT_STATION_NO = 111X
    
    alt Pallet Exists at 111X
        DB-->>Op: Record Found
        Op-->>Op: Log: Destination 111X is busy.
    else Station 111X is Empty
        DB-->>Op: No Record Found
        Op->>DB: UPDATE DNPallet SET CURRENT_STATION_NO = 111X WHERE CURRENT_STATION_NO = 110X
        DB-->>Op: Update Success
        Op->>TS: Send ID05 (110X -> 111X)
        TS-->>Op: Command Accepted
    end
	
:::

### **2.2  Pallet Full Process**

**Station Process**

::: mermaid
flowchart LR
    B1[1111: Robot Station] --> C1[1111: Storage Station] 
    B2[1112: Robot Station] --> C2[1112: Storage Station] 
    B3[1113: Robot Station] --> C3[1113: Storage Station] 
    B4[1114: Robot Station] --> C4[1114: Storage Station]
    B5[1115: Robot Station] --> C5[1115: Storage Station] 
:::

**Flow Process**

::: mermaid
graph TD
    A[Start: AGC sends ID26 Normal Completion] --> B[WMS: Find Pallet by Current_Station 111X]
    B --> C[Fetch DNStoragePlan Data<br/>via BATCH_STATION_NO]
    
    subgraph Update Inventory
        C --> D[Update DNStock:<br/>Item_Code & Plan_Qty]
        D --> E[Update DNPallet:<br/>EMPTY_FLAG = 0]
        E --> F[Update DNStoragePlan:<br/>Increment PROCESS_QTY]
    end
    
    F --> G{Find Empty Location<br/>in PLAN_AREA?}
    G -- No --> H[Wait / Manual Intervention]
    G -- Yes --> I[Update DNPallet:<br/>STATUS_FLAG = 1, STATION_NO = Location]
    
    I --> J[Create DNWorkInfo & DNCarryInfo]
    J --> K[Send ID05: Transfer to Location]
    K --> L([End: Move Started])
:::

**Sequence Diagram**

::: mermaid
sequenceDiagram
    participant AGC as AGC / Robot
    participant WMS as WMS Logic
    participant DB as WMS Database
    
    AGC->>WMS: Send ID26 (Normal Completion @ 111X)
    
    Note over WMS, DB: 1. Inventory Updates
    WMS->>DB: Get Pallet ID from 111X
    WMS->>DB: Sync DNStock with DNStoragePlan Data
    WMS->>DB: Set DNPallet.EMPTY_FLAG = 0
    WMS->>DB: Increment DNStoragePlan.PROCESS_QTY
    
    Note over WMS, DB: 2. Storage Allocation
    WMS->>DB: Search Empty Location (DNSTORAGEPLAN.PLAN_AREA)
    DB-->>WMS: Return Loc: Empty Location No
    
    WMS->>DB: Update DNPallet (Status=1, Current_Station_no=Location)
    WMS->>DB: Insert DNWorkInfo & DNCarryInfo
    
    WMS->>AGC: Send ID05 (Move to Empty Location No)
:::


**Data Flow Diagram**

::: mermaid

graph LR
    ID26[ID26 Signal] -- "Trigger" --> Logic[WMS Logic]
    Plan[(DNStoragePlan)] -- "Batch Info" --> Logic
    Logic -- "Update" --> Stock[(DNStock)]
    Logic -- "Find Space" --> Warehouse[(Warehouse Map)]
    Logic -- "Generate" --> Work[(DNWork/Carry Info)]
    Work -- "ID05" --> AGC[[AGC System]]
:::

| Table | Target Column | New Value / Action | Logic |
| --- | --- | --- | --- |
| **DNStock** | `ITEM_CODE` | `DNStoragePlan.ITEM_CODE` | Matches stock to the active batch |
| **DNStock** | `PLAN_QTY` | `DNStoragePlan.BATCH_QTY_CTRN_PL` | Updates qty to "Full Pallet" count |
| **DNPallet** | `EMPTY_FLAG` | **0** | Marks pallet as "Loaded" |
| **DNPallet** | `STATUS_FLAG` | **1** | Reserved for storage movement |
| **DNPallet** | `CURRENT_STATION_NO` | **Empty Location ID** | "Virtually" moves pallet to rack |
| **DNStoragePlan** | `PROCESS_QTY` | `+ BATCH_QTY_CTRN_PL` | Updates total processed count |
